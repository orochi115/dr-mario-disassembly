# Dr. Mario Chinese text, read by tools/build_text.py (see its header for the syntax).
#
#   ERASE  SCREEN COL ROW W H TILE   nametable cells -> TILE
#   FILL   SCREEN X Y W H COLOR      pixels -> colour (X/Y like COL/ROW)
#   TEXT   SCREEN ID COL ROW TEXT    text drawn on the screen's nametable
#   DYN    SCREEN ID COL ROW TEXT    text the code draws (emitted as tile rows)
#
# COL/ROW: top-left of the first 16x16 character cell, in tiles, "+n"/"-n" adds
# pixels. The 11x11 ink of a character sits 2 px right and 3 px down in its cell.
